3

Integrasi Pembayaran Digital (Midtrans Gateway) — Opsional

Stand Anda dapat menerima pembayaran cashless digital (QRIS, GoPay, ShopeePay, Virtual Account BCA/Mandiri/BRI) langsung ke rekening Anda sendiri tanpa perantara perbankan kampus melalui akun merchant Midtrans mandiri.

1 Daftar Akun Midtrans

Daftar di dashboard.midtrans.com. Buka menu Settings → Access Keys untuk melihat Merchant ID, Client Key, dan Server Key.

2 Input di Profil Stand

Buka menu /tenant/settings, isi kolom Merchant ID, Client Key, dan Server Key Anda dengan cermat.

3 Pilih Mode & Aktifkan

Pilih mode Sandbox (uji coba/demo) atau Production (uang riil), nyalakan switch "Aktifkan Midtrans Gateway", lalu klik Simpan.

Keamanan Enkripsi Kredensial Stand Anda

Server Key Anda dienkripsi secara otomatis menggunakan algoritma militer AES-256-CBC sebelum disimpan ke basis data. Pihak lain tidak dapat membaca kunci rahasia transaksi Anda.

Webhook Notification URL (Auto-Update Pembayaran)

Agar pesanan otomatis berubah menjadi Dibayar saat mahasiswa selesai transfer, salin URL berikut ke dashboard Midtrans Anda di menu Settings → Configuration → Payment Notification URL:

https://canteen.feb.ac.id/api/midtrans/notification
4

Mode Tunai Otomatis & Kebijakan Keranjang Tunggal

Belum Punya Akun Midtrans? Tetap Berjualan Normal!

Penggunaan Midtrans sepenuhnya opsional. Jika kredensial kosong atau gateway dimatikan, sistem Smart Canteen FEB secara cerdas menerapkan Graceful Fallback. Mahasiswa yang memesan dari stand Anda tetap bisa memesan dengan metode Tunai (Bayar Cash di Stand) tanpa error apapun.

Kebijakan Keranjang Tunggal (Single-Tenant Checkout)

Sama seperti aplikasi food delivery terkemuka, 1 keranjang pemesanan hanya memuat menu dari 1 stand kantin. Jika mahasiswa ingin memesan dari stand lain, sistem akan meminta konfirmasi ganti stand terlebih dahulu. Ini menjamin pesanan Anda tidak tertukar dan langsung masuk ke dapur stand Anda.

Cara Memverifikasi Pembayaran Tunai

  1. Buka menu Verifikasi Pembayaran di sidebar (/tenant/verify-payment).
  2. Arahkan kamera HP/laptop ke QR Code di layar HP mahasiswa, atau ketik kode manual format FEB-8921.
  3. Aplikasi akan menampilkan rincian pesanan dan total tagihan rupiah.
  4. Terima uang fisik dari mahasiswa, lalu klik tombol 💵 Konfirmasi Pembayaran Tunai.
