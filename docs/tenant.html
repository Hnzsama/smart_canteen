Cara Memverifikasi Pembayaran Tunai

  1. Buka menu Verifikasi Pembayaran di sidebar (/tenant/verify-payment).
  2. Arahkan kamera HP/laptop ke QR Code di layar HP mahasiswa, atau ketik kode manual format FEB-8921.
  3. Aplikasi akan menampilkan rincian pesanan dan total tagihan rupiah.
  4. Terima uang fisik dari mahasiswa, lalu klik tombol 💵 Konfirmasi Pembayaran Tunai.
