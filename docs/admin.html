4

Tata Kelola Biaya Terpusat (Centralized Fee Governance)

Untuk memastikan harga makanan tetap wajar dan tidak ada biaya tersembunyi yang memberatkan mahasiswa, seluruh komponen biaya non-makanan dikendalikan secara eksklusif oleh Administrator di menu /admin/payment-settings.

1. Biaya Layanan Aplikasi (Platform Fee) app_fee

Biaya operasional pemeliharaan sistem Smart Canteen FEB (default: Rp 1.000 per transaksi). Disimpan di tabel app_settings. Biaya ini sama untuk seluruh stand dan hanya diatur oleh Admin.

2. Biaya Saluran Pembayaran (Gateway Fee) channel_fee

Biaya transaksi resmi dari switching provider (contoh: QRIS 0.7%, BCA VA Rp 4.000, atau Rp 0 untuk Tunai). Dikelola di tabel payment_methods oleh Admin agar tarifnya transparan dan terstandarisasi.

Aturan Bisnis Kunci untuk Admin:

Tenant tidak memiliki akses untuk menambah markup atau memanipulasi app_fee maupun channel_fee. Tenant hanya mengelola harga murni item menu mereka sendiri.

Mengapa Single-Tenant Cart Diberlakukan?

Sistem e-commerce makanan skala besar (seperti ShopeeFood) memberlakukan checkout per stand. Pada Smart Canteen FEB, kebijakan ini mencegah kegagalan pembayaran ganda antar akun Midtrans stand yang berbeda, serta mempermudah dapur stand memproses pesanan secara mandiri.

Keamanan Enkripsi Kredensial

Seluruh midtrans_server_key milik stand disimpan di basis data menggunakan enkripsi kuat AES-256-CBC melalui Laravel Encrypted Casts, melindungi kerahasiaan merchant bahkan dari kebocoran SQL dump.
