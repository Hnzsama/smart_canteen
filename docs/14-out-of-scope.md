# Out of Scope

Fitur berikut TIDAK termasuk dalam proyek:

- Mobile application
- Native Android/iOS application
- Sistem keuangan
- Laporan keuangan kompleks
- Accounting
- Settlement system
- Sistem inventory kompleks
- Integrasi POS
- Integrasi sistem kampus
- WhatsApp notification
- SMS notification
- Email notification infrastructure
- Push notification
- Real-time infrastructure kompleks
- Multi-campus management
- Loyalty program
- Voucher system kompleks
- Membership system
- Advanced analytics
- Advanced reporting
- Production-grade payment infrastructure
- Infrastructure scaling
- DevOps pipeline kompleks
- Kubernetes
- Microservices
- AI recommendation
- Machine learning
- Fitur lain yang tidak tercantum dalam scope

Jika fitur tersebut dibutuhkan, fitur dianggap sebagai
CHANGE REQUEST / OUT OF SCOPE dan harus mendapat persetujuan terlebih dahulu.
